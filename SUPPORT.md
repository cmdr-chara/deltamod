# Support

## Bugs and feature requests

Use the [issue templates](https://github.com/cmdr-chara/deltamod/issues/new/choose) for problems affecting Deltamod Community. Before reporting a bug, check for an existing issue and include:

- Deltamod Community version;
- operating system and architecture;
- affected game and game version;
- mod name and source;
- exact reproduction steps;
- expected and observed behavior;
- sanitized logs or screenshots when useful.

Individual mods may support only specific game versions. Compatibility problems caused solely by a mod should first be reported to that mod's author.

## Security vulnerabilities

Do not open a public issue for a vulnerability. Follow [SECURITY.md](./SECURITY.md) and use GitHub private vulnerability reporting.

## Upstream project

Deltamod Community and the original Deltamod project are separate applications. Report a problem to [upstream Deltamod](https://github.com/deltamodders/deltamod/issues) only when it affects the original project and is not specific to this community fork.

## Support expectations

This is a community project maintained on a best-effort basis. Response and resolution times are not guaranteed. Please avoid duplicate reports and do not share copyrighted game files, credentials, tokens, or other private data.
