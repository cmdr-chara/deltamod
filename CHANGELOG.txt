# Deltamod Community 2.0.10

Released 2026-08-14.

This stable release introduces a Deltamod-themed Windows setup experience and
keeps the release documentation aligned with the packages published for every
supported desktop platform.

## Highlights

- Add a custom Tauri setup shell for Windows with the same pixel-art visual
  language as Deltamod, selectable installation destination, live progress,
  integrity verification, and launch controls.
- Keep the installer fully graphical on Windows without opening a console
  window.
- Publish the standard Debian package for Linux and separate DMGs for Intel and
  Apple Silicon Macs.
- Update the README to point to the current stable release and document the
  actual `.deb` installation flow.

# Deltamod Community 2.0.9

Released 2026-08-13.

This maintenance release keeps the stable package layout tidy, closes the
remaining npm audit finding, and keeps the Linux manual-download package
reliable on GitHub-hosted runners, and fixes recursive artifact hashing during
release publication.

## Fixed

- Publish the Linux `.deb` bundle from Ubuntu 22.04. The upstream `linuxdeploy`
  AppImage path is currently failing in GitHub Actions, so the stable release
  uses the native Debian package until that toolchain is fixed upstream.
- Update the transitive `nanoid` dependency to 3.3.18, fixing the high-severity
  custom-generator denial-of-service advisory reported by `npm audit`.

- Generate `SHA256SUMS.txt` from artifact files in their downloaded subfolders,
  so release publication handles GitHub's merged artifact layout correctly.

# Deltamod Community 2.0.5

Released 2026-08-13.

This maintenance release hardens the Linux Tauri dependency graph, fixes
cross-platform bundle icons, and tidies
the repository layout without changing the application protocol or user-data
location.

## Fixed

- Patched the GTK3/GLib `VariantStrIter` unsoundness reported by
  GHSA-wrw7-89jp-8q8g using the upstream two-line fix while Tauri still pins
  GTK3/GLib 0.18.
- Removed duplicate per-crate Cargo lockfiles; the Tauri workspace now uses
  its single reviewed lockfile as documented.
- Moved release/platform documentation and legacy launchers into dedicated
  directories while preserving their commands and rollback behavior.

# Deltamod Community 2.0.3

Released 2026-08-12.

This is the first stable release using the Tauri desktop shell. Download it
manually from the GitHub release page. In-app automatic updates are not enabled;
they will remain unavailable until a signed updater is configured.

Windows and macOS packages are not code-signed because this community project
does not currently have paid platform signing credentials. Operating systems
may show an unknown-publisher warning. Verify downloads against the attached
`SHA256SUMS.txt`; checksums verify file integrity, not publisher identity.

## Highlights

- Added a theme-aware animated startup sequence.
- Redesigned the Mod Shop with clearer source cards, image previews, loading
  states, search controls, and download/import progress.
- Improved GameBanana featured sorting and guarded pagination against duplicate
  requests.
- Improved Nexus Mods request coalescing, quota tracking, rate-limit handling,
  and authorization messaging.

## Fixed

- Resolved production dependency audit failures and updated vulnerable
  transitive dependencies.
- Stabilized the Electron smoke test by waiting for renderer navigation to
  finish before continuing.
- Prevented repeated external-catalogue requests while another request is still
  active.

## Nexus Mods status

Nexus Mods account connection is not enabled in this build because the
Deltamod Community application registration is still pending. The app shows a
pending-registration state instead of requesting or storing pasted API keys.
GameBanana, ModDB, and local mod imports remain available.

## Known limitations

- Windows and macOS artifacts are unsigned and may trigger platform warnings.
- Linux and macOS support remains experimental.
- Automatic updates are not available; install future releases manually from
  the official GitHub release page.
- Nexus Mods browsing and downloads will remain unavailable until application
  registration is approved and a future build supplies the SSO application ID.
